# 🔐 Cybersecurity Awareness Chatbot - Part 2

## 📋 Project Overview

This is **Part 2** of the Cybersecurity Awareness Chatbot project. The application is a **GUI-based chatbot** that educates South African citizens about online security threats including phishing scams, password safety, safe browsing, and privacy protection.

The chatbot features a professional black/cyan themed interface with voice greeting, ASCII art logo, keyword recognition, random responses, memory recall, sentiment detection, and conversation flow.

---

## 🎯 Features Implemented

| # | Feature | Description |
|---|---------|-------------|
| 1 | **GUI Design** | Black background with cyan text, professional layout, buttons for Send, Voice, Clear |
| 2 | **Voice Greeting** | Plays WAV audio file at startup with user's real voice |
| 3 | **ASCII Art** | Cybersecurity logo displayed on application launch |
| 4 | **Keyword Recognition** | Recognizes: password, phishing, scam, privacy, 2fa, safe browsing, help |
| 5 | **Random Responses** | Multiple responses per topic (4-5 each) randomly selected |
| 6 | **Conversation Flow** | Handles "tell me more", "another tip", "more information" |
| 7 | **Memory & Recall** | Remembers user's name and interests throughout conversation |
| 8 | **Sentiment Detection** | Detects worried, confused, curious, frustrated emotions |
| 9 | **Error Handling** | Default responses for unknown inputs without crashing |
| 10 | **Code Structure** | Modular OOP with Dictionary, Lists, and separate classes |
